VESPER / ETF ROTATION

换一种尺度，再看动量。Look at momentum across horizons.

同样叫动量，计算的方式不同，看到的市场也会不同。这个项目把几种定义放在同一条研究流程里，先比较，再把参数放到后面的时间里检验。Momentum looks different depending on how it is measured. This project compares several definitions in one workflow, then tests chosen parameters on later periods.

机制流程Mechanism功能组成Capabilities流程与界面设计Design study研究边界Scope
01

四种动量定义Four momentum definitions

比较回归动量、简单动量、12–1 动量与风险调整动量。Compare regression, simple, 12–1 and risk-adjusted momentum.

02

参数研究Parameter research

支持网格搜索、贝叶斯优化及多组窗口组合，研究参数对结果的影响。Use grid search, Bayesian optimization and window combinations to explore parameter sensitivity.

03

滚动验证与评估Rolling validation

支持 Walk-forward 分析，并记录波动、回撤、换手和交易成本等指标。Support walk-forward analysis and evaluate volatility, drawdown, turnover and transaction costs.

DESIGN NOTES / 设计推演DESIGN STUDY

把配置、运行和复查接起来。Connect setup, execution and review.

从现有项目的功能出发，梳理操作顺序与信息层次。以下界面是为介绍项目绘制的设计示意，不是运行截图。These design studies organize the existing project’s capabilities into a workflow and information hierarchy. The interface below is an illustrative concept, not a running application screenshot.

  1. 01

    明确比较对象Define the comparison

    先固定研究问题，再决定候选动量与窗口组合。Fix the question before choosing momentum methods and window combinations.

  2. 02

    分开训练与检验Separate fitting and testing

    参数搜索与后续验证分开呈现，保留实验的时间边界。Separate parameter search from later validation, preserving time boundaries.

  3. 03

    留下运行记录Keep run records

    记录配置、任务与输出，让下一次比较有据可循。Keep configuration, jobs and outputs together for later comparisons.

配置分层Layer the configuration

基础设置、训练参数和风控分别组织，减少单页负担。Group setup, training and risk controls instead of crowding one form.

运行与历史并列Keep runs near history

把队列和历史记录留在近处，方便复查实验差异。Keep queues and history nearby to review differences between experiments.

研究边界Research scope

参数搜索可能拟合历史噪声。滚动测试只是验证过程的一部分，不能证明未来有效；这里不展示收益承诺。Parameter search can fit historical noise. Rolling tests are one part of validation and do not establish future effectiveness. No performance promise is presented here.
