VESPER / MARKET SENTIMENT

价格之外，也听听人们在说什么。Beyond prices, look at the conversation.

讨论的热闹与价格的涨落，并不总是同一件事。这个项目尝试把公开讨论变成可以整理和比较的文本样本，再观察情绪指标究竟留下了什么信息。A busy conversation is not the same as a price move. This project organizes public discussion into comparable text samples and explores what sentiment measures might contain.

01

ASI 加权情绪Weighted ASI

ASI = Σᵢ wᵢ sᵢ / Σᵢ wᵢ wᵢ = ln(1+vᵢ) · (1+cᵢ) · [1+ln(1+uᵢ)] · 2^(−aᵢ/h)

对应 metrics.py：s 为情绪分数，v 为阅读数，c 为回复数，u 为转发数；a 为非负帖龄（小时），h 为半衰期（小时）。未评分帖子跳过，未启用衰减时末项为 1；权重和为 0 时源码返回 0，应与真实中性样本区分。Matches metrics.py: s is sentiment score, v reads, c replies, u reposts; a is non-negative age in hours and h the half-life. Unscored posts are skipped; disabled decay is 1. A zero denominator returns 0 in code and should be distinguished from observed neutral sentiment.

02

讨论量变化Posting-volume change

gₜ = Nₜ / Nₜ₋₁ − 1

同长度、同来源窗口内比较有效帖子数 N。这是通用变化率定义；前期为 0 时不计算百分比，需展示原始计数和采集覆盖情况。Compare valid post counts N across equal-length windows and consistent sources. This is a general change-rate definition; if the prior count is zero, report counts and collection coverage rather than a percentage.

RESEARCH COMPANION

先看谁在说，再看说了什么。Read the sample before the score.

阅读项目时，先沿着输入与输出走一遍，再展开值得追问的细节。以下是验证思路，不表示这些检查已全部完成。Follow the inputs and outputs, then explore the questions below. These are validation approaches, not claims that every check has been completed.

02 / OUTPUT

情绪指标、有效样本量及采集覆盖说明；一起查看变化。Sentiment indicators, valid sample counts and collection coverage, read together.

再往下问一步QUESTIONS TO TAKE FURTHER

01指标突然改变，是情绪还是样本？Sentiment shift or sampling change?+

比较来源构成、有效帖子数和采集完整性，再阅读 ASI。少量高互动帖子可能明显改变加权结果。Compare source mix, valid post counts and collection completeness before reading ASI. A few highly engaged posts can move a weighted score substantially.

02同一句话，模型与词典会一致吗？Will dictionary and model scores agree?+

抽样复核否定、反讽、引用和金融术语。记录评分方法及版本，不把不同方法产生的分数直接串成一条历史。Review negation, sarcasm, quotations and financial terminology. Record scoring method and version rather than concatenating incompatible score histories.

研究边界Research scope

讨论样本可能有选择偏差、灌水和时间错配。情绪标签不是价格预测，模型扩展也不等于已部署服务。Discussion samples can contain selection bias, spam and timing mismatches. Sentiment labels are not price forecasts, and optional integrations are not deployed-service claims.
