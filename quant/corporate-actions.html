VESPER / CORPORATE ACTIONS

一笔分红，也要把来处记清。Keep the history behind each dividend.

行情里的一次跳变，有时来自一笔分红。这个项目把不同来源的分红送转记录放在一起，做融合、校验和回溯，为后续的数据处理留下一份更清楚的底稿。A discontinuity in a price series can begin with a dividend. This project brings corporate-action records together, with merging, validation and historical follow-up to support later data work.

机制流程Mechanism功能组成Capabilities流程与界面设计Design study研究边界Scope
01

多源融合Source reconciliation

接入东方财富、巨潮资讯与门户数据兜底，合并分红送转记录。Combine EastMoney, CNInfo and portal fallback records.

02

质量校验Quality checks

在进入主表前执行字段与记录质量校验，减少来源差异对下游的影响。Check fields and record quality before merging into the master table.

03

增量与回溯Incremental updates

支持增量更新及历史未实施记录回溯，持续维护事件状态。Support incremental updates and follow-up on historical actions that have not been implemented.

DESIGN NOTES / 设计推演DESIGN STUDY

让每条记录都能找到来处。Keep each record traceable.

从现有项目的功能出发，梳理操作顺序与信息层次。以下界面是为介绍项目绘制的设计示意，不是运行截图。These design studies organize the existing project’s capabilities into a workflow and information hierarchy. The interface below is an illustrative concept, not a running application screenshot.

  1. 01

    定义一条事件Define the event

    先确定关键字段与日期的含义，再考虑怎样合并。Define key fields and dates before deciding how records merge.

  2. 02

    把差异展开Expose differences

    来源不一致时保留对照，避免只留下一个无法解释的结果。Keep source comparisons available when records differ.

  3. 03

    持续跟进状态Revisit status

    增量更新之外，也给尚未实施的历史记录留一条回溯路径。Keep a follow-up path for historical actions alongside incremental updates.

主表保持简洁Keep the master table concise

常用字段留在表格，来源细节进入侧栏。Keep frequent fields in the table and source detail in a side panel.

冲突有单独入口Give conflicts a review path

把待复核记录集中呈现，便于逐条查看原始依据。Collect records for review with a path to their source evidence.

多来源并不自动等于准确。事件状态与关键日期需要结合原始公告复核。Multiple sources do not guarantee accuracy. Event status and important dates need checking against original announcements.
