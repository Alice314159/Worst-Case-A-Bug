VESPER / ETF MONITOR

把变化记下来，再决定要不要行动。Notice the change before acting on it.

研究之外，还需要一张能反复查看的观察表。ETF Monitor 把行情更新、技术面变化和风险提示串起来，让值得复核的地方先浮出来。Alongside research, there is the need for a repeatable monitoring routine. ETF Monitor brings updates, technical changes and risk flags together so there is a clearer place to begin a review.

机制流程Mechanism功能组成Capabilities流程与界面设计Design study研究边界Scope
01

行情维护Price updates

下载配置中的 ETF／指数日 K，使用本地缓存，并校验返回名称与监控对象是否一致。Download configured ETF/index daily bars, reuse cached data and check returned names against the intended instruments.

02

技术面预警Technical flags

观察 5 日与 20 日均线、均线方向、近期高点回撤，支持定时扫描与终端报告。Track 5/20-day moving averages, their direction and drawdown from recent highs, with scheduled scans and terminal reports.

03

因子与状态模块Factor and regime modules

后端包含溢价、份额、情绪、拥挤等因子模块，以及同类资产分组标准化和市场状态模块。Backend modules cover premium, shares, sentiment and crowding factors, with asset-bucket normalization and market-regime components.

DESIGN NOTES / 设计推演DESIGN STUDY

先看变化，再展开依据。Find the change, then inspect the evidence.

从现有项目的功能出发，梳理操作顺序与信息层次。以下界面是为介绍项目绘制的设计示意，不是运行截图。These design studies organize the existing project’s capabilities into a workflow and information hierarchy. The interface below is an illustrative concept, not a running application screenshot.

  1. 01

    整理观察对象Define the universe

    把监控对象、行情更新与名称校验放在流程前面。Place instrument selection, price updates and name checks first.

  2. 02

    区分提示与行动Separate flags from action

    指标变化先成为观察线索，再由人决定是否继续处理。Treat indicator changes as review prompts before any further action.

  3. 03

    保留复核路径Keep an evidence trail

    预警旁边保留指标与任务记录，方便追溯。Keep indicators and task records close to the flag.

总览先给重点Prioritize the overview

把需要查看的变化放在前面，细节按需展开。Lead with changes worth reviewing and reveal detail as needed.

执行状态另成一层Separate execution state

数据更新、指标计算和观察结果分别呈现。Distinguish data updates, indicator calculation and observations.

研究边界Research scope

预警是待检查的线索，不代表交易已执行。Alerts are prompts for review, not evidence of an executed trade.
