# 默认语言与手动选择

优先顺序：

1. 本机手动选择（`wcab-lang`），中文和英文均优先。
2. 本次浏览会话中尚未过期的地区语言结果（30 分钟）。
3. Cloudflare 请求地区：`request.cf.country === 'CN'` 时中文，其余或未知地区英文。

公开接口：`GET /api/locale`，只返回 `{"language":"zh"}` 或 `{"language":"en"}`。
地区来自 Cloudflare 提供的入站请求信息，不读取客户端传来的国家或 IP 头。
此接口不写数据库、不创建访问事件，也不保存或返回原始 IP。
回应禁止缓存，并沿用网站来源白名单；不需要管理员密钥。

手动切换后，不会被正在返回的地区请求覆盖。后续导航会记住手动选择。
在代理或 VPN 下，识别的是出口地区。无法连接接口时使用英文，仍允许手动切换。
本地预览不模拟真实国家，地区判断返回英文或在本地后台不可用时回退英文。

线上 Worker 已具备此接口；前台更新需随网站发布后生效。
