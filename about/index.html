02 — 量化研究

先证伪，再下单。

主要做 A 股日频多因子选股与中低频择时。研究流程固定：假设 → 因子构造 → 分层回测 → 交易成本与容量检验 → 小仓位实盘跟踪半年。没过检验的想法一律归档，不上仓位。

工具链 Python / Polars / DuckDB，数据落本地 Parquet，回测引擎与因子库自研并逐步开源。
